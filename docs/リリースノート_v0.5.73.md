# WSL Codex GUI v0.5.73

Codex CLI `0.172.0`への対応を確認し、接続前にもフッターを表示するようにしました。

## 更新内容

- 未接続・接続中・切断中も、状態と選択中の接続先をフッターに表示します。未接続時は接続ボタンの案内も表示します。
- 接続後は従来のモデル、推論レベル、速度、利用枠、残高、CLI版数などを表示します。
- Codex CLI `0.172.0`を確認済み版に追加し、app-serverプロトコル基準970ファイルを更新しました。

## インストール

実行中のWSL Codex GUIを終了し、`WslCodexGui_0.5.73_x64-setup.exe`を実行してください。既存の設定を保持して上書き更新します。Windows 10/11（x64）、WebView2 Runtime、別途インストールしてサインイン済みのCodex CLIが必要です。インストーラーは未署名です。
