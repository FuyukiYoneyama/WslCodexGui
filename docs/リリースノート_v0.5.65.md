# WSL Codex GUI v0.5.65

モデルが混雑して処理に失敗したとき、原因と対処法を日本語で表示するよう改善しました。

WSL Codex GUIは、Codex CLIをWindowsのデスクトップ画面から操作する非公式アプリです。Windows 10/11（x64）向けにNSISインストーラーを配布します。

**ダウンロード版の警告:** インストーラーは未署名です。以前のブラウザ取得版でEdgeとWindows SmartScreenの警告を確認しています。配布元と下記のSHA-256を確認し、続行するかご自身で判断してください。

## 0.5.65での更新

- モデル混雑時に「選択中のモデルが混雑しているため、処理を完了できませんでした」と表示します。
- 時間を置いて再送する方法と、画面下部の「🧠」から別のモデルを選んで再送する方法を、同時に案内します。
- 元の英文や問い合わせ用の追加情報は「詳細」で確認できます。バナーは「閉じる」ボタンで消せます。
- 自動再試行中は黄色の案内で「自動で再試行しています。そのままお待ちください」と表示し、出力が再開すると案内を消します。
- 処理終了の通知でも説明を維持し、エラーのJSONがそのまま表示される問題を修正しました。

## インストールと更新

1. `WslCodexGui_0.5.65_x64-setup.exe`と`.sha256`ファイルをダウンロードします。
2. 下記SHA-256を確認し、使用中のWSL Codex GUIを終了して、エクスプローラーからセットアップを実行します。旧版からは同じ場所へ上書き更新します。
3. Codex CLIを別途インストールし、サインインします。Ollamaを使う場合はWindows側にOllama CLIを別途インストールし、使うモデルを取得してください。

## 動作環境と既知の制限

- Windows 10/11（x64）。WebView2 Runtimeが必要です。
- 確認済みCodex CLIは`0.165.0`です。今回の変更はエラーの表示処理です。
- この改善は混雑の原因を説明するもので、モデル側の混雑そのものを解消するものではありません。
- Ollamaではモデルによってツール呼び出しが正常に動作しない場合があります。
