# WSL Codex GUI v0.5.63

WSL Codex GUIは、Codex CLIをWindowsのデスクトップ画面から操作する非公式アプリです。Windows 10/11（x64）向けにNSISインストーラーを配布します。

**ダウンロード版の警告:** インストーラーは未署名です。ブラウザ取得版でEdgeとWindows SmartScreenの警告が確認されています。配布元と下記のSHA-256を確認し、続行するかご自身で判断してください。

![ブラウザ取得版の起動時に表示されたSmartScreen警告（ユーザー提供の画面）](https://raw.githubusercontent.com/FuyukiYoneyama/WslCodexGui/master/docs/images/smartscreen-warning-v0.5.62.png)

## 0.5.63での修正

- Ollamaプロバイダを選び、Windows側のローカルAPIが停止している場合、インストール済みのOllama CLIを`ollama serve`で起動します。
- モデル一覧の取得に成功したら、以前の取得失敗メッセージを消します。
- モデル一覧取得時のWindowsコンソール表示を抑えます。

## インストールと更新

1. `WslCodexGui_0.5.63_x64-setup.exe`をダウンロードします。
2. 下記SHA-256を確認し、エクスプローラーからセットアップを実行します。旧版からは同じ場所へ上書き更新します。
3. Codex CLIを別途インストールし、サインインします。Ollamaを使う場合はWindows側にOllama CLIを別途インストールし、使うモデルを取得してください。

## 動作環境と既知の制限

- Windows 10/11（x64）。WebView2 Runtimeが必要です。
- プロジェクトの確認済みCodex CLIバージョン一覧には`0.164.0`が含まれます。
- Ollamaではモデルによってツール呼び出しが正常に動作しない場合があります。
