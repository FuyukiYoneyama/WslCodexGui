# v0.5.60 リリースノート草案

> 公開前の草案です。公開する版が変わった場合は、版数・検証結果・SHA-256を更新します。

WSL Codex GUIは、Codex CLIをWindowsのデスクトップ画面から操作する非公式アプリです。初回公開版はWindows 10/11（x64）向けのNSISインストーラを配布します。

## 主な機能

- WSL2内またはWindows上のCodex CLIに接続し、チャットで作業を依頼
- スレッドの再開・名前変更・アーカイブ、承認要求への応答
- 画像の貼り付け、モデルと推論レベルの選択、使用量の表示
- Ollamaへの接続

## インストールと更新

1. [Releases](https://github.com/FuyukiYoneyama/WslCodexGui/releases)から`WslCodexGui_0.5.60_x64-setup.exe`をダウンロードします。
2. 下記のSHA-256を確認し、エクスプローラーからセットアップを実行します。
3. Codex CLIを別途インストールし、サインインします。WSLモードではWSL2内、Windows-nativeモードではWindows側に導入してください。

旧版から更新するときは新しいセットアップを実行します。旧版のアンインストール画面が表示された場合、設定を残すには「アプリケーションデータを削除する」を選ばずに進めます。

## 動作環境と既知の制限

- Windows 10/11（x64）。WebView2 Runtimeが必要です。
- プロジェクトの確認済みCodex CLIバージョン一覧には`0.164.0`が含まれます。Codex CLIの更新で動作が変わる場合があります。
- インストーラは電子署名されておらず、Windows SmartScreenが警告を表示する場合があります。
- Ollamaではモデルによってツール呼び出しが正常に動作しない場合があります。
