# WSL Codex GUI v0.5.62

WSL Codex GUIは、Codex CLIをWindowsのデスクトップ画面から操作する非公式アプリです。Windows 10/11（x64）向けにNSISインストーラーを配布します。

## 主な機能

- WSL2内またはWindows上のCodex CLIに接続し、チャットで作業を依頼
- スレッドの再開・名前変更・アーカイブ、承認要求への応答
- 画像の貼り付け、モデルと推論レベルの選択、使用量の表示
- Ollamaへの接続

## 0.5.62での修正

- 初回起動時のプロジェクトパスを空欄にし、利用するフォルダーを選んでから新しいスレッドを作るように変更
- WSLのフォルダー参照を、未選択時は対象ディストリのホームフォルダーから開始
- 旧版からの更新は、インストーラーを一度起動すると同じ場所へ上書き。旧版のアンインストール操作を省き、保存済み設定とショートカットを引き継ぐ

## インストールと更新

1. [Releases](https://github.com/FuyukiYoneyama/WslCodexGui/releases)から`WslCodexGui_0.5.62_x64-setup.exe`をダウンロードします。
2. 下記のSHA-256を確認し、エクスプローラーからセットアップを実行します。既存の旧版がある場合は、そのまま更新されます。
3. Codex CLIを別途インストールし、サインインします。WSLモードではWSL2内、Windows-nativeモードではWindows側に導入してください。

## 動作環境と既知の制限

- Windows 10/11（x64）。WebView2 Runtimeが必要です。
- プロジェクトの確認済みCodex CLIバージョン一覧には`0.164.0`が含まれます。Codex CLIの更新で動作が変わる場合があります。
- インストーラーは電子署名されておらず、Windows SmartScreenが警告を表示する場合があります。
- Ollamaではモデルによってツール呼び出しが正常に動作しない場合があります。
- Windows SandboxでWSLディストリの取得に失敗した際、対処案の表示まで数十秒かかりました。
