# WSL Codex GUI v0.5.71

Codex CLI `0.171.0`を確認済みバージョンへ追加しました。

WSL Codex GUIは、Codex CLIをWindowsのデスクトップ画面から操作する非公式アプリです。Windows 10/11（x64）向けにNSISインストーラーを配布します。WebView2 Runtimeが必要です。

## 更新内容

- WSL上のCodex CLI `0.171.0`で、接続初期化、スレッド操作、モデル一覧、ワークスペース内のGit書き込みを確認しました。
- 保存済みのapp-serverプロトコル基準を`0.171.0`に更新しました。既存のGUI操作に使う要求と応答を実機で照合しました。

## インストール

1. 下のSHA-256を照合し、実行中のWSL Codex GUIを終了してください。
2. `WslCodexGui_0.5.71_x64-setup.exe`を実行してください。旧版からは同じ場所へ上書き更新します。
3. 初めて使う場合は、Codex CLIを別途インストールしてサインインしてください。

インストーラーは未署名のため、Windows SmartScreenが警告を表示することがあります。
